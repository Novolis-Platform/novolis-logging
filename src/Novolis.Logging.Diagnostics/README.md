# Novolis.Logging.Diagnostics

Provides a bounded, app-private diagnostic journal for `ILogger` records and
early exception capture. The journal contains operational metadata and errors;
applications must not log user content.

## Install

```bash
dotnet add package Novolis.Logging.Diagnostics
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (net10.0).
